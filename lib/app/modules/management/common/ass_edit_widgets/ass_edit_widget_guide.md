# AssEditWidget 功能操作说明

## 1. 组件定位

`AssEditWidget` 是一个面向业务页面的字幕编辑组件，用于把媒体资源和 `ASS` 字幕内容绑定在一起，提供以下能力：

- 媒体播放与暂停
- 波形预览与时间定位
- 字幕逐句编辑
- 词级 `\k` 标签编辑
- 句子新增与合并
- 音频/视频同步预览
- 编辑结果回调

它本身是一个业务壳组件，实际底层编辑能力由 `AssMediaSubtitleEditorWidget` 承载。

## 2. 适用场景

适合以下场景使用：

- 字幕审核
- 字幕精修
- 音频字幕对齐
- 视频字幕对齐
- 卡拉 OK 字幕逐词时间调整
- 翻译字幕辅助查看或编辑

## 3. 主要入参

### 必传参数

- `mediaUrl`
  - 媒体资源地址
  - 可为音频或视频

- `ass`
  - 原始 `ASS` 字幕文本

- `mediaType`
  - 媒体类型
  - 常见值为音频或视频

### 可选参数

- `translateAss`
  - 翻译字幕内容

- `playbackRate`
  - 播放速度

- `hideAddSentence`
  - 是否隐藏“添加句子”按钮

- `hideTranslation`
  - 是否隐藏翻译相关区域

- `rightToolButtons`
  - 右侧扩展工具按钮

- `envelopeTopFloatWidget`
  - 波形区域上方的扩展浮层

- `playbackControlBarBuilder`
  - 自定义底部播放控制栏

- `playbackActionBarBuilder`
  - 自定义波形下方附加操作栏

- `onChanged`
  - 编辑结果回调

## 4. 页面结构

组件整体可以分成三大区域：

### 4.1 字幕列表编辑区

用于展示和编辑所有句子。

支持内容：

- 每句字幕的时间
- 每句的主文本
- 每句的词级拆分
- 每句的中文翻译

交互说明：

- 普通点击整个句子 `item` 时，会跳到该句开始时间
- 当前会从句首开始播放，并在句尾自动停止
- 点击后会同步高亮当前句子的波形区域
- 如果高亮波形区域已经超出当前可视范围，波形区域会自动滚动并尽量居中
- 如果当前正在多选合并模式，点击句子会变成选中或取消选中该句，而不是触发播放定位
- 如果当前已经处于某句编辑态，点击其他句子会先提示保存当前编辑内容

### 4.2 波形与播放器区域

位于底部，负责媒体预览和时间定位。

支持内容：

- 显示音频波形
- 显示当前播放位置
- 句子时间范围可视化
- 缩放时间轴
- 左右平移时间轴

### 4.3 视频预览区域

当 `mediaType` 为视频时，底部右侧会额外显示一个小视频预览窗。

作用：

- 播放媒体时同步查看字幕所对应的画面
- 在审核或精修视频字幕时更直观

## 5. 支持的主要操作

### 5.1 播放与暂停

支持方式：

- 点击底部播放按钮
- 在非文本输入状态下按空格键

组件会自动同步：

- 当前播放时间
- 当前高亮句子
- 当前高亮词
- 列表自动跟随定位

### 5.2 切换上一句 / 下一句

底部控制栏支持：

- 上一句
- 下一句

常用于快速在句子之间跳转和核对时间。

### 5.3 缩放波形

底部控制栏支持：

- 缩小
- 放大
- 重置

作用：

- 查看更长时间范围
- 查看更细粒度的局部时间点

### 5.4 平移波形

支持方式：

- 控制栏左右按钮
- 在波形区域中滚动查看

用于查看当前可视范围之外的时间片段。

补充说明：

- 当通过点击整个句子 `item` 触发定位时，如果当前句子的高亮波形段已经超出可视区域，组件会自动将该高亮段滚动到中间附近
- 如果高亮波形段本身就在当前可视区域内，则不会额外滚动，避免界面抖动

### 5.5 编辑句子内容

可对单句进行编辑，包括：

- 起始时间
- 结束时间
- 原文文本
- 词级文本
- 翻译文本

编辑后组件会重新计算句子文本和 `\k` 标签内容，并触发回调。

### 5.6 添加句子

当 `hideAddSentence = false` 时，右侧工具栏会显示“添加句子”按钮。

作用：

- 在当前字幕列表中新增句子
- 适合字幕缺句、分句不完整的场景

### 5.7 拖拽合并句子

非编辑态下支持将一个句子拖到另一个句子上。

当前规则：

- 仅支持连续的两句进行合并
- 不连续句子不可直接合并

适合场景：

- 原分句过碎
- 两句实际应为一句

### 5.8 多选合并

右侧工具栏支持切换到“多选合并”模式。

可执行：

- 选择多个句子
- 合并选中的句子
- 取消当前合并模式

### 5.9 自动定位当前句子

媒体播放时，组件会根据当前时间自动找到所属句子。

联动表现：

- 当前句子高亮
- 当前词高亮
- 列表自动滚动到对应句子

### 5.10 翻译显示控制

当 `hideTranslation = true` 时：

- 翻译相关区域隐藏

适用于：

- 只审核原文字幕
- 不需要展示翻译内容的页面

## 6. 编辑结果回调

组件通过 `onChanged` 对外回传编辑结果。

返回内容通常包括：

- 最新的 `ass`
- 最新的 `translateAss`
- 最新的句子结构列表

业务页面常见用法：

- 用户边改边回调
- 控制器拿到最新字幕内容后执行保存

## 7. 常见业务接法

示例：

```dart
AssEditWidget(
  mediaUrl: data.mediaUrl ?? "",
  mediaType: data.mediaTypeEnum,
  ass: data.ass ?? "",
  hideAddSentence: true,
  hideTranslation: true,
  playbackRate: 1.0,
  onChanged: (value) {
    controller.saveEditAss(value);
  },
)
```

该接法表示：

- 加载一个媒体资源
- 使用已有 `ASS` 字幕进入编辑
- 隐藏添加句子
- 隐藏翻译区域
- 每次编辑变化后回调给控制器保存

## 8. 操作建议

推荐使用流程：

1. 先播放媒体，确认当前句子与时间范围
2. 逐句检查开始时间与结束时间
3. 再检查句子文本和词级拆分
4. 如句子切分不合理，再执行新增或合并
5. 最后整体播放一遍验证同步效果

## 9. 注意事项

- `mediaUrl` 为空时无法完成媒体准备
- `ass` 内容为空时，编辑器可进入，但不会有有效字幕结构
- 连续两句之外的句子不支持直接拖拽合并
- 视频模式下会额外加载视频预览，页面资源占用更高
- 回调 `onChanged` 可能较频繁，外部保存逻辑应避免做过重操作

## 10. 总结

`AssEditWidget` 可以理解为一个“字幕审核与精修工作台”。

它把下面几件事整合到了一个组件里：

- 媒体播放
- 波形定位
- 句子编辑
- 词级编辑
- 合并与新增
- 视频预览
- 结果回传

如果业务页面需要的是“在音频或视频上做字幕对齐和审核”，优先考虑使用这个组件。
