# 模块详情页重构说明

## 目标与验收口径
- 第一阶段先对齐前台课程详情页的主骨架，再按需回挂一小块后台专属中间卡片区
- 后台模块详情页改为与前台一致的主骨架：
  - 单元纵向列表
  - 底部悬浮单元切换栏
  - 单元头部采用三段式横向结构
  - lesson 区域采用前台同款圆形卡片网格
- 当前阶段的定制差异：
  - 单元头部左侧不显示底部进度信息
  - 圆形 lesson 卡片不显示进度环、完成态、选中态、新题目标记
  - 在单元头部和 lesson 网格之间增加后台管理卡片区：
    - 左侧上下两张卡片：单元计划、课时计划
    - 右侧两张卡片：文章、歌曲

## 改动点列表
- 重写 `manage_module_detils_view.dart` 页面结构，移除旧版顶部模块大头部
- 页面内容调整为接近前台 `official_course_details_view.dart` 的层级：
  - 主列表
  - 底部悬浮操作栏
- 单元 section 改为：
  - 左侧标题
  - 中间学习按钮组
  - 右侧单元目标按钮
- 在单元头部和 lesson 之间新增固定高度的管理卡片区，并接回老版本的生成能力：
  - `generateUnitPlan`
  - `generateLessonPlan`
  - `generateLessonTitle`
  - `generateLessonArticle`
  - `generateLessonSong`
- 将底部按钮从“管理教材”调整为“管理单元”，新增管理单元弹窗：
  - 标题为“管理单元”
  - 内容区为最多四列的 1:1 拖拽网格
  - 单元卡片展示封面、难度标签、拖动标签、标题
  - 底部提供“取消”“保存排序”按钮，其中保存排序暂未接业务逻辑
- lesson 列表改为固定 7 列的圆形卡片网格，并保留标题、时长占位和“题目列表”按钮的结构位置

## 关键设计 / 关键决策
- 联动逻辑已收回 `ManageModuleDetilsController`，view 只负责渲染和事件转发
- 为了保证底部 tab 与列表联动稳定，中间卡片区使用固定高度布局，并同步更新 controller 中的 section 高度估算
- 复用现有后台 controller 中已有的单元目标/题目列表跳转能力
- 中间学习按钮组当前仅用于还原 UI 结构，不额外接入前台学习流程
- 管理单元弹窗当前只做本地拖拽排序体验，不在当前轮次提交排序到服务端
- 中间管理卡片区仅接入你明确指定的“生成”相关逻辑，其余文案先写死

## 兼容性影响与注意事项
- 旧版顶部操作区、单元管理区、课时管理区入口仍未整体回挂到新页面
- 新增的中间卡片区只回挂了老版本中的部分生成能力
- 由于后台实体缺少前台 lesson 的进度/时长等字段，本轮仅对齐展示结构，不补状态展示
- 管理单元弹窗中的拖拽排序不会影响当前页面数据，关闭弹窗后不持久化
- 文章/歌曲卡片中的“查看”“关联”目前仅保留 UI 位置，未接业务逻辑
