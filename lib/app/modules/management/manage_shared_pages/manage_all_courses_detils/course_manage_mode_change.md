## 目标与验收口径

- 课程详情正常态下不展示“添加模块”卡片。
- 底部操作区不再展示“新增级别 / 排序”，改为“管理课程”按钮。
- 点击“管理课程”进入管理态；管理态底部按钮切换为“退出管理”。
- 管理态布局调整为左侧两列模块区 + 右侧暂存拖动区。
- 左侧模块卡片复用当前课程详情模块卡片样式，仅隐藏“展开 / 收起 unit”入口，并在封面左上角增加拖动图标；模块详情、编辑、删除、封面图裁剪/编辑等能力保持可用。
- 浏览态下点击模块卡片主体不再直接跳转模块详情，而是展开 / 收起下方的 unit 卡片区域。
- 管理态下点击模块卡片主体无反应，仅支持长按整张模块卡片进行拖拽排序。
- 管理态中显示“添加模块”卡片，并允许点击添加模块。

- 底部按钮改为“管理课程 / 退出管理”切换。

## 关键设计 / 关键决策

- 当前管理端课程详情接口没有现成的 `moveModule` 能力，因此管理态拖拽采用“本地工作区”模式：
  - 管理态内拖拽先只更新本地列表和暂存区；
  - 点击“退出管理”时统一把各 Level 的 `moduleIds` 保存到后台；
  - 若暂存区还有模块，则提示用户继续编辑或放弃本次拖拽调整。
- 管理态继续保留左侧网格内的“添加模块”卡片入口；右侧暂存区底部同时提供“新增级别 / 级别排序”按钮，底部主操作仍统一通过“退出管理”结束本次管理态操作。

## 兼容性影响与注意事项

- 浏览态中的模块详情仍可通过 unit 卡片进入；模块卡片主体点击改为展开 unit。
- 管理态下仅隐藏展开 unit 相关 UI，并禁用模块卡片主体点击；其余按钮操作保持原有行为。
- 若用户在管理态中拖拽后未清空暂存区直接退出，本次模块排序调整不会保存，并会回退到服务端最新状态。
