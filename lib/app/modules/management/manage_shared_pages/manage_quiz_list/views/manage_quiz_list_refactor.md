# 题目列表页底部工具条重构说明

## 目标与验收口径
- 重构 `manage_quiz_list_view.dart` 底部工具条为左中右三段式布局
- 题目卡片左上角勾选框常显
- 题目卡片右上角删除图标替换为拖动图标
- 底部仅保留本次确认的操作：刷新课时计划、重新生成题目、新建题目、关联题目、全选、取消全选、上架、下架、删除、模拟体验、全部/上架/下架筛选

## 改动点列表
- `manage_quiz_list_view.dart`
  - 移除旧底部统计区、刷新列表、批量操作开关等旧入口
  - 使用 `PlatformBackdropFilterWidget` 直接承载底部毛玻璃容器
  - 新增左中右三组按钮区
  - 左侧补充“刷新课时计划”“重新生成题目”按钮
  - “新建题目”按钮改为跳转 `ManageSelectQuziKnowledgeView`
  - 右侧新增前端筛选按钮组，并显示全部/上架/下架数量
- `manage_quiz_list_controller.dart`
  - 新增当前筛选状态
  - 新增筛选后的列表 getter
  - 新增筛选计数 getter
  - 新增“当前可见项全选/取消全选”逻辑
  - 新增复用旧模块详情页的“刷新课时计划 / 重新生成题目 / 选择题目知识点”动作
- `manage_module_detils_controller.dart`
  - 跳转 `MANAGE_QUIZ_LIST` 时补充 `unitId / lessonTemplateId / difficultyMin / difficultyMax / language` 参数
- `manage_quiz_public_widget.dart`
  - 右上角删除图标替换为拖拽图标

## 关键设计与决策
- 筛选为纯前端筛选，不请求服务端
- 全选/取消全选作用于当前筛选后可见的题目项
- 已选题目在切换筛选后暂不自动清空，批量操作仍对当前已选集合生效
- 当筛选不是“全部”时，列表排序入口暂不开放，避免筛选子集排序与完整列表排序语义冲突
- “刷新课时计划”“重新生成题目”直接复用旧模块详情页单课时动作
- “刷新课时计划”“重新生成题目”在题目列表页中改为直接调用，不再二次确认弹窗
- “新建题目”沿用旧“管理题目”的真实链路，跳转到 `ManageSelectQuziKnowledgeView`
- 若页面入口未提供 `unitId` 或 `lessonTemplateId`，按钮点击时提示上下文缺失，不做兜底推断

## 兼容性影响与注意事项
- `关联题目` 沿用原有逻辑
- `模拟体验` 改为优先体验当前筛选结果中的第一题
- 单题删除入口已从卡片右上角移除，本次保留批量删除入口
- 从模块详情页进入题目列表时，已补齐创建题目所需上下文参数
- 其他历史入口若未传递完整参数，仍可查看题目列表，但左侧新增动作会按上下文校验后提示
