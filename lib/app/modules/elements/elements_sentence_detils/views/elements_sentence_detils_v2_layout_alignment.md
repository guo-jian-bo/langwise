# 句子详情页结构对齐说明

## 目标与验收口径

- 将句子详情页外层结构对齐到当前单词/短语详情页
- 页面面包屑右侧补充通用配置按钮
- 去掉右侧浮动按钮区
- 将记忆按钮移动到顶部标签区右侧
- 页面右侧内容顺序调整为：
  - 标签 + 记忆按钮
  - 句子正文
  - 释义
  - 蓝图区
  - 四宫格分析入口

## 改动点列表

- `elements_sentence_detils_view.dart`
  - 面包屑改为 `BreadcrumbWidget(actionWidget: GeneralSettingButtonWidget())`
  - 内容区改为与单词/短语页一致的 `Padding + LockOverlayWidget(showBack: false)` 结构
- `elements_sentence_detils_v2_content_widget.dart`
  - 去掉 `ElementsDetailLayout`
  - 改为直接使用 `Row` 组织左右结构
  - 删除右侧浮动按钮整组代码
  - 新增顶部记忆按钮及其弹窗入口

## 关键设计与决策

- 左侧媒体区本次继续沿用现有实现，不额外重做
- 只收页面结构和操作入口位置，不调整四宫格数据逻辑
- 记忆按钮文案继续保持句子页自身语义：`记句子 / 已记忆`

## 兼容性影响与注意事项

- 句子分析子页跳转逻辑保持不变
- 句子详情页原有的记忆弹窗逻辑保留，只调整触发入口位置
- 右侧浮动按钮中的配置、语言、等级、记忆入口本次统一下线
