# 词素网格卡片内容块改造说明

## 目标与验收口径
- 将词素卡片网格视图里“媒体区域下方的内容块”调整为词典单词卡片同款信息布局。
- 标题仍显示单词内容，但需要保留词素片段高亮效果。
- 保持 `us/uk` 发音胶囊、`gloss` 原文/译文显示规则、`definition` 回退规则与词典单词卡片一致。

## 改动点列表
- 修改 `elements_morpheme_detils_grid_view_widget.dart` 中 `ElementsMorphemeDetilsUnifiedCardWidget` 的内容块布局。
- 新增本地 `gloss` 解析逻辑，按当前展示语言模式决定显示内容。
- 新增本地发音胶囊播放组件，复用现有 `ElementsPronunciationCapsuleButton` 和音频播放能力。

## 关键设计与决策
- 只在当前词素网格视图文件内实现，不抽公共层，控制影响面并保持最小 diff。
- 外层卡片结构、媒体区域、底部类型/难度信息条保持不变。
- 内容块切换为左对齐信息流：标题 -> 发音胶囊 -> gloss/definition。

## 兼容性影响与注意事项
- 不修改词典卡片公共实现，不影响其他单词/短语/句子卡片。
- `gloss` 为空时，非“原文语言”模式下回退显示 `definition`。
- 发音胶囊仅在存在可播放音频时展示。

## 非目标
- 不调整网格布局参数。
- 不修改星云视图。
- 不重构现有公共卡片组件。
