# 单词详情页语法画像弹窗说明

## 目标与验收口径
- 单词详情页顶部译文右侧由 `grammaticalTypeNids` 渲染出来的语法标签，支持点击。
- 点击后弹出“语法画像”弹窗。
- 弹窗正文只展示当前点击语法类型在 `grammaticalProfiles` 中对应的中文说明。

## 改动点列表
- 单词详情页顶部语法标签改为可点击交互。
- 新增语法画像弹窗展示逻辑，弹窗标题为“语法画像”。
- 顶部可点击语法标签与弹窗内语法标签均增加右箭头提示。
- 弹窗内语法标签支持点击切换说明内容，不必关闭后重新打开。
- 单词详情实体补充解析根级字段 `grammaticalProfiles`，供页面按 `grammaticalTypeNid` 查找对应说明。

## 关键设计 / 关键决策
- 只改单词详情页，不改短语页与句子页。
- 弹窗样式沿用项目现有 `DialogUserWidget`，结构参考句子详情页槽位弹窗。
- 弹窗正文只取 `grammaticalProfiles[].descriptions` 中 `lang == "zh"` 的文本；没有中文则不做本地兜底。
- 弹窗头部保留当前单词与全部语法标签，当前点击标签高亮，其余标签弱化显示，并支持点击切换。

## 兼容性影响与注意事项
- 若后端未返回 `grammaticalProfiles` 或对应项缺少中文说明，点击标签时仅提示“暂无语法画像”。
- 现有顶部标签的展示顺序仍然完全跟随 `grammaticalTypeNids`。
