# 单词详情内容区重排说明

## 目标与验收口径

- 将 `ElementsWordDetilsContentWidget` 改为“内容区域 + 底部 tabbar”结构。
- 内容区域按 `460:375` 严格拆分上半区和下半区。
- 上半区左侧媒体区域保持 `1:1`，宽高都等于上半区高度。
- 接入接口新增字段 `lexicalSetPreview`，用于展示“同义反义”。
- 标题信息区改为：
  - 标题 + 发音按钮
  - `gloss` 中文 + 标签
  - `descriptions` 中文
- 发音区不再复用深层旧封装，直接在当前页面内按既有 UI 拉平实现。

## 改动点列表

- `card_word_detils_entity.dart`
  - 新增 `lexicalSetPreview` 字段与对应实体。
- `elements_word_detils_content_widget.dart`
  - 重排整体布局。
  - 新增上半区标题信息区、发音区、同义反义区实现。
  - 复用并重组词源、语法、短语、句子、构词展示区域。

## 关键设计与关键决策

- `lexicalSetPreview` 保持与后端字段一一对应，放在详情顶层实体，不在 view 内临时解析。
- `gloss` 和 `descriptions` 只取中文；没有中文时直接不显示，不做兜底。
- 没词源时，下半区只保留短语和句子两列。
- 没发音时，标题行右侧发音按钮不显示；没发音且没构词时，上半区第二块整块隐藏。
- 短语和句子默认都存在，不增加单列占满逻辑。

## 兼容性影响与注意事项

- 不改 controller 请求流程与页面外壳。
- 不修改现有详情跳转目标，只重组页面承载布局。
- 构词内部展示尽量复用原有实现，减少行为回归。
