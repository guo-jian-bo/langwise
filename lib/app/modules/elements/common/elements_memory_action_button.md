# ElementsMemoryActionButton 说明

## 目标与验收口径

- 提供一个统一的“加入记忆 / 已加记忆”按钮公共组件
- 供单词、短语、句子详情页复用同一套按钮样式
- 组件只负责按钮 UI 与点击事件透传，不承载具体业务逻辑

## 改动点列表

- 新增 `elements_memory_action_button.dart`
- 暴露可配置参数：
  - `favorited`
  - `onTap`
  - `normalText`
  - `favoritedText`
  - `color`

## 关键设计 / 关键决策

- 保持按钮高度、圆角、图标、字号、禁用态透明度一致
- 默认文案使用：
  - `加入记忆`
  - `已加记忆`
- 点击逻辑不下沉到公共组件，仍由各详情页自己处理

## 兼容性影响与注意事项

- 当前只统一按钮表现层，不统一单词、短语、句子的加入记忆业务逻辑
- 若后续按钮交互出现明显差异，应优先在调用方处理，不在组件内追加业务分支
