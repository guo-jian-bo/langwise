# 目标与验收

- 目标：调整短语详情页同义反义卡片中的标签样式，使其与语法标签保持一致。
- 验收：同义反义标签使用 `WordInflectionInfoTagWidget` 渲染，颜色沿用当前词性标签颜色；当标签在卡片可见区域内放不下时，尾部显示 `+n`。

# 改动点

- 在 `elements_phrase_detils_content_widget.dart` 中将同义反义标签切换为语法标签同款样式。
- 基于卡片当前可用宽高计算可见标签数量，并在溢出时追加 `+n` 标签。

# 关键设计

- 标签直接复用 `WordInflectionInfoTagWidget` 默认样式，和语法区组件保持一致。
- 溢出判断只作用于当前卡片可见区域，不改“更多”跳转与接口数据结构。

# 兼容性影响与注意事项

- 仅影响短语详情页同义反义卡片展示。
- 当标签数量较少或空间充足时，仍完整展示，不会出现 `+n`。
