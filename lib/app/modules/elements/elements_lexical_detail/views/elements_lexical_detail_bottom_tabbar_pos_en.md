# 同义反义详情页底部词性改为英文

## 目标与验收口径
- 目标：同义反义详情页底部 `TabBar` 中的词性文案不再优先显示中文，改为优先显示英文。
- 验收：进入同义反义详情页后，底部各语义项前的词性标签展示效果与单词/短语详情页底部 `TabBar` 保持一致。

## 改动点列表
- 调整 `elements_lexical_detail_view.dart` 中底部 `TabBar` 词性文案的取值优先级。

## 关键设计/关键决策
- 仅调整底部 `TabBar` 的词性展示，不改头部、卡片区、同反义面板中的其他文案逻辑。
- 取值顺序改为：英文 -> 中文 -> `posAddr` -> `pos`。

## 兼容性影响与注意事项
- 仅影响同义反义详情页底部 `TabBar` 的词性展示文案，不影响语义切换、筛选和其他区域 UI。
