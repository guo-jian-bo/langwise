# 目标与验收

- 目标：调整同义反义详情页左右区域与反义对照区的颜色样式。
- 验收：
  - 左侧同义区域外层边框为 `#F43F5E` 的 `20%`。
  - 右侧反义区域外层边框为 `#3B82F6` 的 `20%`。
  - 反义区域 `poleLabels` 中，`a` 使用 `#93C5FD`，`b` 使用 `#FDA4AF`。
  - `a` 下方分栏背景为 `#3B82F6 12%`、边框为 `#3B82F6 20%`。
  - `b` 下方分栏背景为 `#F43F5E 12%`、边框为 `#F43F5E 20%`。
  - `b` 分栏中 `isCurrent == true` 的卡片边框为 `#FDA4AF`。

# 改动点

- 在 `elements_lexical_detail_view.dart` 中为左右主区域传入不同边框色。
- 调整反义区表头文案颜色与下方 `pole` 容器颜色。
- 通过 `ElementsDictStampCard.borderColor` 参数，实现 `b` 当前项高亮。

# 关键设计

- 对公共词典卡片新增可选 `borderColor` 参数，默认行为保持不变。
- `b` 当前项高亮通过卡片自身边框参数实现，避免额外外层包裹。

# 兼容性影响与注意事项

- 本次只影响同义反义详情页样式，不改跳转与数据结构。
- 若后端 `display.left/right` 顺序变化，颜色会继续按 `pole` 值 `a/b` 匹配，而不是按左右位置写死。
