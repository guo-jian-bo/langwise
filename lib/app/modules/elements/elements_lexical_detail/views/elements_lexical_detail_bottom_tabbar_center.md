# 同义反义详情页底部 TabBar 居中说明

## 目标与验收口径
- 目标：调整同义反义详情页底部语义切换条的宽度表现。
- 验收：当子项较少时，底部切换条按内容宽度收缩并居中显示，不再占满整行；当子项较多时，原有横向滚动与切换交互保持不变。

## 改动点列表
- 在 `elements_lexical_detail_view.dart` 中为底部 `ElementsSemanticBottomBar` 增加居中包裹。
- 不修改 `ElementsSemanticBottomBar` 公共组件内部逻辑，避免影响其他页面。

## 关键设计 / 关键决策
- 采用页面局部调整而不是改公共组件，保持最小 diff。
- 只处理同义反义详情页底部区域，不改上方内容布局和选中态逻辑。

## 兼容性影响与注意事项
- 少量子项时视觉会从整行铺满改为居中胶囊样式。
- 子项较多时仍受父级宽度约束，内部横向滚动能力不变。

## 非目标
- 不调整 Tab 文案、颜色、选中态、点击逻辑。
- 不修改其他页面的同类底部条布局。
