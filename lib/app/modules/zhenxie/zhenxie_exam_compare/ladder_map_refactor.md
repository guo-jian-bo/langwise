## 目标与验收口径
- 将考点详情页“阶梯”模块的 content 区域泳道改为与章法页同构的布局骨架。
- 节点必须固定挂在对应泳道内，不能再出现跨泳道漂移。
- 每个节点封面区内不展示文案，标题统一放在封面底部外侧。
- Gate 覆盖层、泳道底板、列布局关系与章法页保持一致。

## 修改范围
- `controllers/zhenxie_exam_compare_controller.dart`
- `views/zhenxie_exam_compare_view.dart`

## 非目标
- 不改接口结构。
- 不改阶梯模块的点击跳转参数。
- 不改其他模块（文章 / 主题 / 能力）的展示逻辑。

## 关键设计
- 阶梯区横向布局不再按“每条泳道的索引位置”拼列，改为按后端 `order` 还原真实列位。
- Gate 区域改为章法页同款 overlay 方案：列系统是主结构，Gate 只做覆盖层，不再参与主排布。
- 新增 `ladderMapScrollController`，用于同步列滚动和 Gate overlay 的横向偏移。
- 节点尺寸口径改为章法页同款公式：列宽由泳道高度扣除标题区与节点内边距后推导。

## 兼容性与注意事项
- 左侧泳道 rail 仍保留考点详情页较小的宽度口径，避免压缩页面其他区域。
- 节点封面优先使用后端 `coverUrl`，失败时回退现有占位图逻辑。
- 若后端未来调整 `order` 语义，需同步复核阶梯区列位映射。
