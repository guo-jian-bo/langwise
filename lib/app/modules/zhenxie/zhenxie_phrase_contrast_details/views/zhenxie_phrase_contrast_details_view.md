# 目标与验收口径

- 将短语对照详情页改为顶部信息区固定、下方卡片区滚动的结构。
- 卡片区按 4 等宽列展示群组，每个群组列内部可独立上下滚动。
- 保持现有 `isLoading` 与空态逻辑，不改数据获取与卡片内容规则。

# 改动点列表

- 移除原先整页 `CustomScrollView` 的滚动方式。
- 页面主体改为固定标题信息区 + `Expanded` 卡片列区域。
- 信息区样式进一步对齐 figma `_Container`：左侧改为“小标题 + 大标题 + 描述”，右侧标签改为纵向排列。
- 群组区域改为 4 列 `Row + Expanded` 布局，超过 4 个群组暂不处理。
- 每列使用带头部的容器结构，头部固定，卡片列表通过 `ListView.separated` 独立滚动，并将容器边框、底色、内边距调到 figma `Container` 风格。

# 关键设计与关键决策

- 每张卡片外层保留 `346 / 546` 的比例约束，继续兼容 `ElementsDictReadCard` 的高度要求。
- 群组不足 4 个时保留空列，确保整体始终是 4 等宽分栏。
- 视觉上参考 React 的 `section` 结构，使用圆角、描边和分隔线组织每列。

# 兼容性影响与注意事项

- 仅调整当前详情页 View 层布局，不修改 controller、接口参数、实体结构和通用组件。
- 顶部信息区不再参与滚动，描述文本过长时会直接占用顶部固定区域高度。

# 待确认问题或 TODO

- 当前按需求忽略超过 4 个群组的展示策略，后续如出现该数据形态需再补充交互方案。
