# 甄写 · 考点接口 API 文档

> 对应需求文档：[`04.exam.md`](./04.exam.md)
> 对应后端实现：`ZhenXieExamController`
> 受众：Flutter App / 前端同学

当前文档覆盖这 7 个主要接口：

- `GET /write/zhenxie/exam/home`
- `POST /write/zhenxie/exam/compare/{module}`
- `POST /write/zhenxie/exam/compare/goals/sankey`
- `GET /write/zhenxie/exam/compare/region/group/list`
- `GET /write/zhenxie/exam/task/query/meta/group/list`
- `POST /write/zhenxie/exam/task/pages`
- `GET /write/zhenxie/exam/task/detail`

说明：

- 旧接口 `GET /write/zhenxie/exam/compare/query/meta/group/list` 已移除，不再使用。
- 对比页和桑基图接口仍接收 `ZhenXieExamCompareRequest`。
- 但当前后端筛选逻辑只识别 `filters` 中 `code = regionNids` 的项，其他 code 不生效。

颜色相关总约定：

- 通用颜色块统一使用 `ColorBlock[]`
- 颜色索引统一使用 `ZhenXieExamColorDTO[]`
- 标签自身带色仍使用 `ZhenXieExamLabelDTO.colors`
- 首页能力模块 `items[]` 当前**不直接下发 colors**，而是下发 `groupCode = ladder / basic`，前端据此决定使用哪组图例颜色

---

## 1. 接口总览

| 接口 | 用途 |
|---|---|
| `GET /write/zhenxie/exam/home` | 获取考点首页 2x2 聚合数据 |
| `POST /write/zhenxie/exam/compare/{module}` | 获取三关对比模块数据 |
| `POST /write/zhenxie/exam/compare/goals/sankey` | 获取能力桑基图数据 |
| `GET /write/zhenxie/exam/compare/region/group/list` | 获取卷别 / 地区筛选元数据 |
| `GET /write/zhenxie/exam/task/query/meta/group/list` | 获取真题列表筛选与排序元数据 |
| `POST /write/zhenxie/exam/task/pages` | 获取真题分页列表 |
| `GET /write/zhenxie/exam/task/detail` | 获取真题详情 |

## 2. 首页接口

### 2.1 请求

- 方法：`GET`
- 路径：`/write/zhenxie/exam/home`

### 2.2 参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---:|---|---|
| `stage` | string | 否 | `xiaoshengchu` | 当前考段：`xiaoshengchu` / `zhongkao` / `gaokao` |

### 2.3 示例

```http
GET /write/zhenxie/exam/home?stage=xiaoshengchu
```

### 2.4 返回

返回类型：`HttpResult<ZhenXieExamHomeDTO>`

这条接口负责首页整屏数据，包含：

- `stage`
- `title`
- `subTitle`
- `headline`
- `summary`
- `stages`
- `blocks`

其中 `blocks[code=goals].items[]` 额外下发：

- `groupCode`：能力分组编码，取值 `ladder` / `basic`

#### `stages[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `stage` | string | 考段编码 |
| `name` | `LanguageText[]` | 考段名称 |
| `taskCount` | int | 该关真题数 |
| `colors` | `ColorBlock[]` | 考段颜色，来源 `en_composition_milestone_exam_reports` |

#### `blocks[]`

首页 4 个 block 固定为：

- `genres`
- `topics`
- `goals`
- `ladder`

通用字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 模块编码 |
| `title` | `LanguageText[]` | 模块标题 |
| `description` | `LanguageText[]` | 模块结论句 |
| `summary` | `LanguageText[]` | 模块摘要短句 |
| `legends` | `ZhenXieExamLabelDTO[]` | 当前仅能力模块使用 |
| `legendDescription` | string | 当前仅能力模块使用 |
| `total` | int | 当前模块总题数 |
| `coveredCount` | int | 当前仅阶梯模块使用 |
| `percent` | int | 当前仅阶梯模块使用 |
| `items` | `ItemDTO[]` | 模块榜单数据 |

#### `blocks[].items[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 当前项编码 |
| `name` | `LanguageText[]` | 当前项名称 |
| `count` | int | 主计数；能力模块下表示主能力题数 |
| `secondaryCount` | int | 当前仅能力模块使用，表示兼考题数 |
| `totalCount` | int | 当前仅能力模块使用，表示主+兼总数 |
| `groupCode` | string | 当前仅能力模块使用，取值 `ladder / basic` |
| `cover` | string | 当前仅阶梯模块使用 |
| `coverUrl` | string | 当前仅阶梯模块使用 |
| `coverMd5` | string | 当前仅阶梯模块使用 |
| `percent` | int | 非能力模块的占比 |
| `colors` | `ColorBlock[]` | 当前项颜色块 |

首页颜色下发口径：

- `stages[].colors`：考段颜色，取 `en_composition_milestone_exam_reports`
- `blocks[code=genres].items[].colors`：文类颜色，取 `en_composition_genres`
- `blocks[code=topics].items[].colors`：主题域颜色，取 `topics`
- `blocks[code=goals].legends[].colors`：能力图例颜色，代码里写死三组能力色中的两组首页口径
- `blocks[code=goals].items[].groupCode`：用于判断每一行是 `ladder` 还是 `basic`
- `blocks[code=ladder].items[]`：当前不下发颜色

## 3. 三关对比接口

### 3.1 请求

- 方法：`POST`
- 路径：`/write/zhenxie/exam/compare/{module}`

### 3.2 路径参数

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `module` | string | 是 | 模块编码：`genres` / `topics` / `goals` / `ladder` |

### 3.3 Body

请求体类型：`ZhenXieExamCompareRequest`

```json
{
  "filters": [
    {
      "code": "regionNids",
      "values": ["beijing", "shanghai"]
    }
  ]
}
```

说明：

- `module=genres` / `topics` 时，如有需要，仍可传 `filters`
- `module=goals` / `ladder` 时，不建议使用 `filters` 做后端筛选
- 能力和阶梯模块如果要做地区切换，按 `ui_ux` 口径由前端基于本地题集自行筛选，并渲染不同效果

### 3.4 当前支持的筛选项

当前后端仅保留 `regionNids` 这一种筛选 code：

| code | 类型 | 说明 |
|---|---|---|
| `regionNids` | `string[]` | 按题目的 `regionNids` 做筛选，命中任一地区即保留 |

### 3.5 当前不生效的筛选项

下面这些虽然放进 `filters` 不会报错，但当前后端不会参与筛选：

- `paperNames`
- 其他任意未识别 code

### 3.6 示例

```http
POST /write/zhenxie/exam/compare/genres
Content-Type: application/json
```

```json
{
  "filters": [
    {
      "code": "regionNids",
      "values": ["beijing", "guangdong"]
    }
  ]
}
```

如果请求的是能力或阶梯模块，建议直接传空 body：

```http
POST /write/zhenxie/exam/compare/goals
Content-Type: application/json
```

```json
{}
```

```http
POST /write/zhenxie/exam/compare/ladder
Content-Type: application/json
```

```json
{}
```

### 3.7 返回

返回类型：`HttpResult<ZhenXieExamCompareDTO>`

返回内容会根据 `module` 不同而变化：

- `genres`：文章对比
- `topics`：主题对比
- `goals`：能力对比
- `ladder`：阶梯对比

其中 `ZhenXieExamCompareDTO.note` 为模块底部说明文案：

- `module=ladder` 时，后端返回：
  `金色角标 = 落在这一关的真题数 · 点一关 → 只看落在这一关的题`

说明：

- 阶梯对比页右侧说明文案请直接使用 `note`
- 左侧三关的 `xx% 可练 · hit/total` 统计当前不由该接口下发，仍由前端基于题集 `coverage` 自行计算
- `module=goals` / `ladder` 时，地区筛选导致的节点压暗、角标变化、样式变化等效果，按 `ui_ux` 口径由前端本地筛题后自行渲染

对比页颜色下发口径：

- `module=genres`
  - `legends[].colors`：家族颜色，来源 `en_composition_families`
  - `legends[].groupCode / groupName`：家族所属文类
- `module=topics`
  - `legends[].colors`：主题域颜色，来源 `topics`
- `module=goals`
  - 当前 `ZhenXieExamCompareDTO` 本身不下发颜色，能力颜色走桑基图接口 `compare/goals/sankey`
- `module=ladder`
  - `legends[]` 不直接带颜色
  - `genreColors`：文章颜色索引，供前端按 `legends[].groupCode` 关联文类颜色，来源 `en_composition_genres`

#### `ZhenXieExamCompareDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `module` | string | 当前模块 |
| `title` | `LanguageText[]` | 页面标题 |
| `description` | `LanguageText[]` | 页面说明 |
| `note` | string | 模块底部解释文案 |
| `legends` | `LegendDTO[]` | 图例列表 |
| `genreColors` | `ZhenXieExamColorDTO[]` | 当前仅阶梯模块使用 |
| `columns` | `ColumnDTO[]` | 三列数据 |

#### `ZhenXieExamCompareDTO.LegendDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 图例编码 |
| `name` | `LanguageText[]` | 图例名称 |
| `count` | int | 三关合计题数 |
| `percent` | int | 三关合计占比 |
| `groupCode` | string | 所属大组编码；如文类、卷别等 |
| `groupName` | `LanguageText[]` | 所属大组名称 |
| `cover` | string | 当前仅阶梯模块使用 |
| `coverUrl` | string | 当前仅阶梯模块使用 |
| `coverMd5` | string | 当前仅阶梯模块使用 |
| `colors` | `ColorBlock[]` | 当前图例颜色块 |

### 4.3 筛选说明

能力桑基图当前不建议使用 `filters` 做后端筛选。

如果页面需要按地区切换能力图，按 `ui_ux` 当前口径：

- 前端基于本地题集自行筛选

## 5. 卷别 / 地区筛选接口

### 5.1 请求

- 方法：`GET`
- 路径：`/write/zhenxie/exam/compare/region/group/list`

### 5.2 用途

返回卷别 / 地区筛选条和弹层共同需要的元数据。

当前实现口径：

- 查询 `en_exam_regions`
- 条件：`gaokaoPaper != null`
- 外层固定返回 5 个值：`天津`、`上海`、`北京`、`新高考全国I卷`、`新高考全国Ⅱ卷`
- 弹层仍按 3 组返回：`自主命题卷`、`新高考全国I卷`、`新高考全国Ⅱ卷`
- 弹层地区项会额外返回 `fixedValue`，用于前端点击内层项后回标外层固定值
- 外层固定值中的 `regionNids` 可直接作为对比接口 `filters.code = regionNids` 的取值来源

### 5.3 返回

返回类型：`HttpResult<ZhenXieExamRegionFilterDTO>`

#### `ZhenXieExamRegionFilterDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `fixedOptions` | `FixedOptionDTO[]` | 外层固定展示的 5 个筛选项 |
| `groups` | `GroupDTO[]` | 弹层里的 3 个卷别分组 |

#### `FixedOptionDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `value` | string | 固定选项值；自主命题卷下取省级 `region nid`，全国卷取卷别名 |
| `name` | string | 固定选项文案 |
| `groupCode` | string | 所属卷别分组 |
| `regionNids` | `string[]` | 当前固定选项命中的地区 nid 列表 |

#### `GroupDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 卷别分组编码 |
| `name` | string | 卷别分组名称 |
| `regions` | `RegionDTO[]` | 当前卷别下的地区列表 |

#### `RegionDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `nid` | string | 地区 nid |
| `name` | `LanguageText[]` | 地区名称 |
| `description` | `LanguageText[]` | 地区说明 |
| `gaokaoPaper` | string | 该地区所属高考卷别 |
| `fixedValue` | string | 点击当前地区后，对应高亮的外层固定值 |
| `sortWeight` | number | 排序权重 |

## 6. 对前端的最终约定

### 6.1 对比 / 桑基图入参

按模块区分：

- `genres` / `topics`：如需后端筛选，可传 `filters.regionNids`
- `goals` / `ladder`：不需要依赖 `filters`，建议传空 body，由前端本地筛选并渲染效果

`genres` / `topics``filters` 示例：

```json
{
  "filters": [
    {
      "code": "regionNids",
      "values": ["regionNid1", "regionNid2"]
    }
  ]
}
```

建议：

- 外层 5 个固定按钮直接用 `fixedOptions`
- 点击弹层地区项时，先取该项的 `fixedValue`，再从 `fixedOptions` 里找到同 value 的 `regionNids` 回传给对比接口

`goals` / `ladder` 示例：

```json
{}
```

如果没有地区筛选，也可以：

- 传 `null`
- 或传空 body
- 或传 `{"filters":[]}`

### 6.2 不要再依赖旧接口

不要再请求：

```http
GET /write/zhenxie/exam/compare/query/meta/group/list
```

请改用：

```http
GET /write/zhenxie/exam/compare/region/group/list
```

## 7. 真题列表筛选与排序元数据接口

### 7.1 请求

- 方法：`GET`
- 路径：`/write/zhenxie/exam/task/query/meta/group/list`

### 7.2 返回

返回类型：`HttpResult<ContentQueryMetaDTO>`

`filters` 当前返回这些分组：

- `regionNids`：卷别 / 地区，固定 5 个值
- `milestone`：考段
- `genreNid`：四文类
- `familyNid`：家族
- `parentNid`：主题域
- `goalNids`：能力，读取各大关 `report.goals`
- `year`：年份

`orders` 当前返回这些分组：

- `stage`：`stage_asc` / `stage_desc`
- `year`：`year_asc` / `year_desc`
- `region`：`region_asc` / `region_desc`
- `family`：`family_asc` / `family_desc`

说明：

- 默认排序项为 `stage_asc`
- 列表排序实际通过 `PageParam.order` 传入
- `year` 当前按固定范围 `2022 ~ 2026` 返回
- `filters` 后端仍支持 `topicNids` / `stageNid` 这类 code，但当前元数据接口不主动下发这几个分组

## 8. 真题分页列表接口

### 8.1 请求

- 方法：`POST`
- 路径：`/write/zhenxie/exam/task/pages`

### 8.2 Body

请求体类型：`ZhenXieExamTaskPageRequest`

常用字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `filters` | `List<Filter>` | 当前列表筛选结构 |
| `content` | string | 搜索关键字，支持题目 / 要点 / 地区 / 家族 / 主题相关检索 |

筛选 code 与元数据接口保持一致，当前主要使用：

- `regionNids`
- `milestone`
- `genreNid`
- `familyNid`
- `parentNid`
- `goalNids`
- `year`

排序不再放在 body 里，走 `PageParam.order`。

示例：

```json
{
  "filters": [
    {
      "code": "milestone",
      "values": ["xiaoshengchu", "gaokao"]
    },
    {
      "code": "familyNid",
      "values": ["picture_based"]
    },
    {
      "code": "year",
      "values": ["2024"]
    }
  ],
  "content": "wildlife"
}
```

排序示例：

```http
POST /write/zhenxie/exam/task/pages?order=year_desc&offset=0&limit=20
```

### 8.3 返回

返回类型：`HttpResult<ZhenXieExamTaskPageDTO>`

`ZhenXieExamTaskPageDTO` 继承 `SimplePage<ZhenXieExamTaskCardDTO>`，除分页字段外，额外补充：

| 字段 | 类型 | 说明 |
|---|---|---|
| `yearRange` | string | 当前筛选结果的年份跨度，如 `2022–26` |
| `milestoneColors` | `ZhenXieExamColorDTO[]` | 列表页全量考段颜色索引 |
| `familyColors` | `ZhenXieExamColorDTO[]` | 列表页全量家族颜色索引 |

说明：

- `yearRange` 取当前筛选后的全量题集最小年份和最大年份，不受当前分页截断影响
- 这个字段对应需求文档里的“右侧 meta 年份跨度”口径
- 卡片内单题年份仍然看 `ZhenXieExamTaskCardDTO.year`
- `milestoneColors` 当前直接返回三关全量颜色，来源 `en_composition_milestone_exam_reports`
- `familyColors` 当前直接返回全量 family 颜色，来源 `en_composition_families`

当前分页项 `list[]` 的单卡结构为 `ZhenXieExamTaskCardDTO`，主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `uid` | long | 真题 uid |
| `milestone` | string | 所属考段：`xiaoshengchu` / `zhongkao` / `gaokao` |
| `milestoneName` | `LanguageText[]` | 考段名称 |
| `year` | int | 年份 |
| `topic` | string | 题目标题 |
| `paperName` | string | 卷名 |
| `requiredPoints` | `string[]` | 要点列表 |
| `regions` | `ZhenXieExamLabelDTO[]` | 地区标签 |
| `family` | `ZhenXieExamLabelDTO` | 家族标签 |
| `topics` | `ZhenXieExamLabelDTO[]` | 主题标签，按题上 `topicNids` 原顺序返回 |
| `stage` | `ZhenXieExamLabelDTO` | 写作阶梯标签 |
| `coverage` | `ZhenXieExamLabelDTO` | coverage 标签 |

## 9. 真题详情接口

### 9.1 请求

- 方法：`GET`
- 路径：`/write/zhenxie/exam/task/detail`

### 9.2 参数

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `uid` | long | 是 | 真题 uid |

示例：

```http
GET /write/zhenxie/exam/task/detail?uid=10001
```

### 9.3 返回

返回类型：`HttpResult<ZhenXieExamTaskDetailDTO>`

当前详情结构主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `uid` | long | 真题 uid |
| `milestone` | string | 所属考段 |
| `milestoneName` | `LanguageText[]` | 考段名称 |
| `year` | int | 年份 |
| `topic` | string | 题目标题 |
| `paperName` | string | 卷名 |
| `section` | string | 题型辅助字段 |
| `wordLimit` | string | 词数要求原文 |
| `wordCount` | `ZhenXieExamWordCountDTO` | 词数范围，结构为 `{min,max}` |
| `fullText` | string | 正文 Markdown |
| `example` | string | 题目引文 |
| `requiredPoints` | `string[]` | 题目要点 |
| `regions` | `ZhenXieExamLabelDTO[]` | 地区标签 |
| `family` | `ZhenXieExamLabelDTO` | 家族标签 |
| `milestoneColors` | `ZhenXieExamColorDTO[]` | 详情页涉及的考段颜色索引 |
| `familyColors` | `ZhenXieExamColorDTO[]` | 详情页涉及的家族颜色索引 |
| `goals` | `ZhenXieExamLabelDTO[]` | 能力标签 |
| `topics` | `ZhenXieExamLabelDTO[]` | 主题标签 |
| `writingStage` | `ZhenXieExamLabelDTO` | 写作阶梯标签 |
| `writingTask` | `ZhenXieExamLabelDTO` | 写作课任务标签 |
| `coverage` | `ZhenXieExamLabelDTO` | coverage 标签 |
| `relatedTaskGroups` | `RelatedTaskGroupDTO[]` | 同类真题分组，前端可直接按组渲染 |

说明：

- `relatedTaskGroups[].code` 当前支持 `family / topic`
- `relatedTaskGroups[].title` 当前分别返回“同一家族 / 同一个主题”
- `relatedTaskGroups[].items` 复用真题列表接口同一个 `ZhenXieExamTaskCardDTO`
- 同一题若同时命中家族与主题分组，优先落在 `family` 组，`topic` 组不再重复下发
- 详情里的 `milestone / milestoneName` 与列表口径保持一致
- `wordCount` 当前直接返回原结构 `{min,max}`，不再拆成 `wordCountMin / wordCountMax`
- `milestoneColors` 会汇总“当前题 + 同类真题分组里出现的卡片”涉及到的考段颜色
- `familyColors` 会汇总“当前题 + 同类真题分组里出现的卡片”涉及到的家族颜色

#### `RelatedTaskGroupDTO`

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | string | 分组编码，当前支持 `family / topic` |
| `title` | `LanguageText[]` | 分组标题 |
| `items` | `ZhenXieExamTaskCardDTO[]` | 当前分组下的真题列表 |

#### `ColorBlock`

| 字段 | 类型 | 说明 |
|---|---|---|
| `theme` | string | 主题色阶，一般为 `LIGHT / DARK` |
| `backgroundColor` | string | 背景色 |
| `borderColor` | string | 边框色 |
| `textColor` | string | 文字色 |
