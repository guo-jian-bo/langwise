## 目标与验收

- 甄写「句法」总览页改为接入 `GET /languages/write/zhenxie/syntax/home`。
- 顶部继续使用项目现有面包屑。
- 页面主体保持 React 当前三列结构：`立 / 变 / 接`，卡片等高铺满。
- 接口成功后严格按数据渲染，不使用本地假数据兜底。

## 改动点

- `zhenxie_syntax_controller.dart`
  - 接入句法首页接口
  - 新增句法首页数据模型
  - 门卡点击改为使用后端 `code` 做路由映射
- `zhenxie_syntax_view.dart`
  - 页面三列、门卡标题、计数、说明改为接口驱动
  - 五张门卡的标本区改为读取 `slotCombinationItems`
  - 分组展示按 React 现有规则重排：`立=句型蓝图+句子金字塔`、`变=句型对照+语法全景`、`接=句间配链`
- `lib/common/https/zhenxie.dart`
  - 新增句法首页请求方法

## 关键设计

- 页面骨架跟词法页保持一致，减少无关视觉漂移。
- 标本区继续留在当前页面内实现，不额外做公共抽象。
- 分组冲突处理：
  - 后端 `groups` 中 `立 / 变 / 接` 与 React 现有列分配不完全一致
  - 当前按用户确认，优先保持 React 分组结构
  - 但每张卡片的标题、说明、计数、标本内容仍然都来自接口
- 句型蓝图的槽位区按既有规则处理：
  - `content` 含英文字母时走实线槽位
  - `content` 不含英文字母时走虚线槽位

## 兼容性与注意事项

- 请求失败时页面显示为空，不回退本地数据。
- 接口字段为空时，有就显示，没有就不显示。
- 句子金字塔继续复用 `句型蓝图` 页面，通过 `supportsPyramid = true` 区分。
