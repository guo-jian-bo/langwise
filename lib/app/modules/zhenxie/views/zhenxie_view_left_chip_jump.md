# 甄写首页左侧标签可点击说明

## 目标与验收口径
- 目标：让甄写首页中“词法 / 句法 / 章法”三张卡左侧标签支持单独点击。
- 验收：
  - 点击标签时，自动连续进入两层页面：先进入对应的词法 / 句法 / 章法页面，再自动进入对应门页。
  - 点击整张卡时，仍保持原先进入对应二级页的行为。
  - 不改动现有卡片布局、样式和其它页面逻辑。

## 改动点列表
- 在 `zhenxie_view.dart` 中给首页 layer card 的 chip 增加点击能力。
- 首页按标签文案映射 `autoOpenDoorCode`，先进入层级页。
- 词法 / 句法 / 章法 controller 读取 `autoOpenDoorCode`，进入层级页后自动继续打开对应门页。

## 关键设计 / 关键决策
- 采用最小 diff，只改首页入口与对应层级 controller，不改各门页实现。
- 标签点击直接复用现有 `TagRoutes.toNamed` 路由，不新增中间封装。
- 为避免影响整卡点击，chip 仅在存在明确目标路由时包一层 `GestureDetector`。
- 自动二跳由二级页 controller 在首帧后触发，这样返回时仍会先回到词法 / 句法 / 章法页。

## 兼容性影响与注意事项
- 词法标签映射到：构词、词源记忆、短语对照、短语配对、搭配组、短语结构、入句画像。
- 句法标签映射到：句型蓝图、句子金字塔、句型对照、语法全景、句间配链。
- 章法标签映射到：段落蓝图、文章蓝图、写作阶梯。
- 写作阶梯不再额外开新页面，而是在进入章法页后自动切到 `map` 视图。
