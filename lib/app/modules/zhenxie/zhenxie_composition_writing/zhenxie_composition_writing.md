# 写作任务列表页

## 目标与验收口径

- 新增 Flutter 管理端“写作任务”列表页。
- 支持从甄写管理台直接进入。
- 支持从写作阶梯卡片的“任务”按钮进入，并带 `stageNid` 只看当前阶梯任务。
- 列表页使用三列网格、底部 `FilterStripWidget`、真实接口分页加载。
- 任务卡整卡可点击，但本轮先保留为占位交互，不接任务详情页。

## 改动点列表

- 新增 `zhenxie_composition_writing` 模块的 binding / controller / view / models。
- 新增写作任务列表与筛选元数据的 `LanguageConsoleRequest` 接口封装。
- 新增甄写写作 catalog 共用卡片骨架与共用拍条 widget。
- 现有写作阶梯卡片切到共用骨架。
- 写作阶梯卡片“任务”按钮改为跳写作任务列表页。
- 甄写管理台中的“写作任务”入口改为真实路由。

## 关键设计 / 关键决策

- 不直接复用现有 `ZhenxieCompositionStageCardWidget` 作为任务卡，因为它已经带有阶梯专属底栏按钮语义。
- 抽一层通用 catalog card 骨架，用于承接阶梯卡和任务卡的共性布局。
- 拍条渲染规则继续复用当前写作阶梯页已经调好的实现，避免两份拍条继续漂移。
- `stageNid` 通过请求体 `filters.code = stageNid` 下发，和接口文档保持一致。

## 兼容性影响与注意事项

- 本轮只做写作任务列表页，不做任务详情和任务编辑。
- 任务卡点击先走占位提示，后续接详情页时再把入口替换成真实跳转。
- 现有写作阶梯卡片结构改为复用共用骨架，但拍条和按钮行为不变。
